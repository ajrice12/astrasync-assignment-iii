# AstraSync Assignment III

The dashboard, figures, and calculations were generated by `AstraSync_Analysis.R`.

## Files

- `index.html`: dashboard for GitHub Pages.
- `AstraSync_Dashboard.html`: standalone dashboard.
- `AstraSync_Analysis.R`: complete R source.
- `Decision_Tree.png`: decision tree for Q2.1.
- `Histogram.png`: ggplot histogram for Q2.4, including mean and median.
- `Sensitivity.png`: sensitivity to bonus and RFP award probabilities.
- `Expected_Payoffs.csv`: expected present values.
- `Monthly_Cashflows.csv`: monthly contributions before terminal rewards.

Run the R source in RStudio with Source or run `Rscript AstraSync_Analysis.R`. It creates an `AstraSync_Output` folder with updated outputs.
